# Retrieved description evidence and limits

This is a deliberately varied **10-record source QA sample**, selected to show
what additional description text establishes and what it does not. It is not
representative of all listings, an individual suitability assessment or an
independent evaluation. Each posting was actually retrieved; none is a synthetic
fixture. The full observed description text is retained in the named real audit
JSON/CSV, including material requirements beyond these paraphrases. A provider's
publication is not confirmation that applications remain open.

“Controlled” means the shared fresh response capture/replay. “Live” means manual
GitHub run [#42193251891](https://github.com/murphym123/career-discovery-engine/actions/runs/42193251891).
The committed `actual-local-records.jsonl` contains the 134 controlled local
records; the live run's 83 local records remain in its full downloadable artifact.
The sealed independent-review packet was not opened; these captures matched no
protected identities. No candidate scores, AI evaluator or ranking changes were
used to produce this report.

The ten cases contain three explicit technical/clinical credential barriers
(Perplexity, FPGA and chiropractor), one explicit 3–5-year communications minimum,
one student/credit condition and one unpaid appointment. These categories are
source facts in a purposeful sample, not estimates of market prevalence. The
four other examples show policy/program, fundraising, membership administration
and security-operations routes with distinct conditions; no personal-fit outcome
is asserted.

JazzHR still supplied the clearest directly relevant policy/program example and
credible outreach/administration adjacency. Live discovery also reached a
communications agency and nonprofit engagement inventory, but their qualifications
show why extra metadata alone cannot prove early-career gains. Ashby supplied
complete bodies for unfamiliar local-option employers, largely experienced or
technical. Lever demonstrated platform reach but no new low-experience policy
opening in this bounded sample. The fix measurably improves evidence availability
and polling balance; it does **not** demonstrate a broad increase in qualified
entry-level opportunities.

All index records remain in the full unranked artifacts. Controlled selection
still omitted 18 local identities that the prior arm retrieved, and 77 of the
fixed arm's 134 local records lacked descriptions. The later live cohort had
26 missing of 83. Missing text, student status, worksite ambiguity, recruitment
pools and uncertain legal-employer labels remain explicit review boundaries.
