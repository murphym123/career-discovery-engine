# DC Career Discovery Engine

A discovery-first research prototype for finding and screening early-career DC-area and relevant remote job opportunities. The engine favors broad job discovery over monitoring a predetermined list of employers.

**Status:** migrating Release 1. Public source APIs may require user-provided credentials; no paid search should run by default. Job relevance scores are preliminary triage heuristics, not hiring probabilities.

## Safety and operations

- Keep API keys in GitHub Actions repository secrets, never source files.
- Do not commit personal resumes, application histories, or SQLite databases to a public repository.
- Use GitHub Actions manually until source quality and costs are validated.
- Follow source terms, rate limits and robots directives.

Repository initialized from the ChatGPT-assisted local prototype.
